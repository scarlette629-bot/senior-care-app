# 每日新劇片單

- 每天台灣時間 06:30 執行 `.github/workflows/series-daily.yml`。
- Netflix 台灣公開台灣作品與節目片庫：讀取推薦首列及「最新作品」列，逐片核對官方作品頁的名稱、節目類型、年份、地區分類、演員及簡介。
- 只自動推薦今年的劇集／綜藝；排除電影、動畫及不能明確分類的作品。雲端執行器所在地的 isAvailable 旗標不能代表台灣可觀看狀態；官方台灣片庫已列出的劇集仍可核對作品資訊，但不宣稱已驗證實際播放。不把作品年份當作精確上架日。
- 台劇、韓劇、陸劇、日劇、歐美劇、綜藝各自查找近七天的新劇新聞；只有新聞的作品列於待核對線索，不自動宣稱已上架。
- 公開來源及區塊不等於全平台完整片庫；不能保證零漏收或個人 Netflix 推薦相同。
- `public/series-discovery.json` 保存來源檢查狀態、最後完整成功時間、官方核對作品及新聞候選。
- `public/entertainment-daily.json` 合併人工片單與有效的自動片單。其他娛樂更新工作也使用同一合併函式，避免下次更新覆蓋新增作品。
- 每片核對期限七天；失敗不推進核對時間。來源部分失敗時顯示警示；全部失敗、官方片庫失敗或沒有本次可核對作品，工作會回報失敗並先發布來源健康狀態。
- 網站顯示實際檢查時間；超過 36 小時標示更新逾期。自動片單超過七天隱藏。
- 原網址、localStorage 及 v1.05 封存內容不修改。

測試：`python -m unittest discover -s tests -p test_series.py -v`；v1.06 分支 `node --test tests/seriesFeed.test.js`。每日工作成功後經既有 Pages 工作部署原網址。

## 近期新片及本週報導修正

每日新片僅列近30天有精確首播／上架日期與日期來源的作品；作品年份、新聞發布日、首次發現或最近核對時間均不代表新片。只有作品資訊但沒有日期證據時，保留在其他推薦或待核對線索。人工交叉核對的跨平台作品由 data/series-recent-reviewed.json 維護，日期證據由 data/series-release-evidence.json 維護。

華語本週報導由 scripts/weekly_hot.py 每小時查詢，按台灣週一至週日判定新聞發布日期，依興趣篩選；不再以歷史週次補位。來源成功但無合格報導與來源失敗分開標示，不宣稱官方熱搜排名。

## 2026-10-27：保留日期不明作品與芒果TV

依使用者確認，30 天作為排除已知舊作品的門檻，不再要求每筆都有確切首播證據。日期不明的官方作品保留並標示待確認；仍不以年份或核對時間宣稱新片。明確未來首播仍列於預定播出。

同一每日 06:30 工作流程新增芒果TV官方最新綜藝片庫 API（`MANGO_URL`）。取最新 80 筆，僅保留官方 `updateInfo` 中日期在最近 30 天的節目；該日期寫入 `latestEpisodeDate`，不冒充首播日期。來源失敗時顯示 partial，保留原核對時間最長七天；過期節目仍由前端每日篩除。沒有官方主持欄位時明確指向官方頁，不補造姓名。

日劇、綜藝仍依興趣篩選；純球類沒有片單，混合興趣仍賽程置頂。v1.05 與 localStorage 不修改。
