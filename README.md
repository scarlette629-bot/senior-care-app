# 🌸 WECARE 暖心守護
## Senior-Friendly Daily Care Web App

> **陪你過好每一天。**  
> A simple, warm, senior-friendly daily care companion.

WECARE 是一套以長者日常生活為核心設計的 Web App，提供用藥提醒、今日行程、飲食紀錄、到家打卡、緊急求助、放大鏡、聽力輔助、天氣提醒、娛樂與賽事資訊、暖心早安圖等功能。

WECARE is a senior-friendly web application designed to support everyday life. It combines medication reminders, schedules, meal records, safe-arrival check-ins, emergency contacts, accessibility tools, weather information, entertainment, sports updates, and daily greeting cards in one easy-to-use interface.

# 🌷 WECARE 簡介 / About WECARE

## 中文
WECARE「暖心守護」的設計目標是讓長者能用更簡單、清楚、安心的方式管理每天生活。

介面以大字體、大按鈕、清楚圖示、簡單操作、語音輔助、日間／夜間模式及長者友善資訊呈現為主要設計方向。

WECARE 不只是健康工具，也希望成為每天都能使用的生活小管家。

## English
WECARE is designed to make everyday digital tasks simpler and more comfortable for older adults.

The interface focuses on large text, large touch targets, clear icons, simple navigation, voice assistance, day/night display modes, and senior-friendly information presentation.

WECARE is designed not only as a health-related tool, but also as an everyday digital companion.

# 🚀 開始使用 / Getting Started

WECARE 為 Web App，可直接使用瀏覽器開啟。

**WECARE Website:** https://scarlette629-bot.github.io/senior-care-app/

# 🏠 首頁 / Home

首頁是 WECARE 的主要資訊中心，可查看今日天氣、用藥、行程、到家打卡、飲食及節目與興趣摘要。

## 🌤️ 今日天氣
可顯示目前溫度、天氣狀況、今日降雨機率與穿衣建議。若無法取得定位，系統可能使用預設地區取得天氣資訊。

## 🔊 小管家問候・今日提醒
點選後，WECARE 可用語音念出問候、天氣、穿衣提醒、降雨機率、尚未完成的用藥提醒及今日待辦。

## 💊 今日用藥
首頁直接顯示近期用藥項目。服藥後按「我吃了」，完成後會顯示「✓ 已吃」。

## 📅 今日行程
首頁會依時間排序顯示今日行程。

## 📍 到家打卡
顯示今天是否已完成平安打卡。

## 🍚 今天吃什麼
顯示今天已記錄幾餐。

## 📺 節目與興趣摘要
依「我的興趣」設定顯示相關運動與影劇資訊。

### English
The Home screen provides a quick overview of weather, medication reminders, today's schedule, safe-arrival status, meal records, and entertainment interests. Tap the daily assistant to hear a spoken summary.

# 💊 吃藥提醒 / Medication

進入「健康 → 吃藥提醒」，輸入藥物名稱及服藥時間，再按「＋ 加入提醒」。

例如：**08:00 血壓藥**

服藥後按「我吃了」，系統會變成「✓ 已吃」。每天的服藥完成狀態會重新開始，但藥物設定會保留。

不再需要的藥物可按「刪除」。也可使用「測試語音提醒」確認裝置是否能正常播放提醒語音。

### English
Enter the medication name and time, then tap **Add Reminder**. After taking the medication, tap **Taken**. Daily completion resets each day while the medication schedule remains stored.

# 📅 今日行程 / Schedule

可新增回診、復健、聚會、運動、採買、家庭活動及其他生活行程。

輸入行程名稱、日期及時間後按「＋ 加入行程」。首頁會自動顯示當日行程並依時間排序。

### English
Use Schedule to record appointments and daily activities. Enter the event title, date, and time, then tap **Add Event**.

# 🍚 飲食紀錄 / Meals

輸入今天吃過的食物，例如「粥、蛋、青菜」，再選擇早餐、午餐、晚餐或點心，WECARE 會保存當天飲食紀錄。

### English
Enter what you ate and select Breakfast, Lunch, Dinner, or Snack. The meal will be stored as part of today's record.

---

# 📍 到家打卡 / Safe Arrival Check-in

到家後進入「首頁 → 到家打卡」，按「我到家了 ❤️」。

WECARE 會記錄日期、時間與目前位置，完成後顯示「✓ 平安到家囉！」。

完成打卡後，可使用裝置分享功能將到家時間與 Google Maps 位置分享給家人，也可透過 WhatsApp 開啟分享流程。

> 使用定位功能時，需要允許瀏覽器取得位置。

### English
Tap **I'm Home ❤️** after arriving safely. WECARE records the date, time, and location and allows you to share the information with family members.

# 🧰 生活工具 / Daily Tools

## 🔍 放大鏡 / Magnifier
利用手機後方相機放大藥袋、菜單、包裝說明、小字文件及商品標示。離開相關功能時，相機會停止使用。

可快速前往古典音樂台、飛碟電台、ICRT、中廣新聞台等官方網站。實際播放功能依各電台網站及瀏覽器支援狀況而定。

# 👂 聽力輔助 / Hearing Assistance

WECARE 提供語音轉大字字幕、環境聲音檢測及測試音等簡易輔助工具。

## 📝 語音轉大字字幕
可將說話內容轉為較大的文字顯示，適合面對面對話或聽不清楚時輔助閱讀。

## 🔊 環境聲音檢測
使用裝置麥克風估算環境聲音的相對強弱，畫面以百分比顯示音量變化。

> 此功能不是專業分貝計，也不能取代正式聽力檢查。

### 麥克風隱私
- 不保存錄音檔
- 停止偵測後會關閉麥克風
- 離開相關功能時會停止使用麥克風

## 🎵 測試音
提供 500 Hz 低頻、1000 Hz 中頻及 4000 Hz 高頻測試音。請從較低音量開始。

### English
WECARE includes speech-to-large-text captions, an environmental sound-level indicator, and test tones. The sound meter is a relative indicator only, not a professional decibel meter. Microphone audio is not saved, and microphone access is stopped when the function is stopped or exited.

# 📺 娛樂與賽事 / Entertainment & Sports

使用者可在「我的 → 我的興趣」選擇棒球、籃球、羽球、桌球、台劇、韓劇、陸劇及綜藝。

首頁會依設定顯示「節目與興趣摘要」。

## ⚾ 台灣職棒
棒球區域可呈現台灣職棒相關賽事資訊。賽事日期、時間與場地可能因聯盟、球隊、天候或其他因素調整，正式資訊應以官方最新公告為準。

### English
Select your interests under **Profile → My Interests**. The Home screen uses these preferences to create a personalized entertainment summary. Sports schedules may change, so verify important event details with official sources.

# 🌅 暖心早安圖 / Morning Greeting

每日會依日期自動選擇不同主題，例如花草日、生活日、晴朗日、療癒日及風景日。

內容包含使用者稱呼、日期、每日問候與暖心文字。不喜歡目前主題時可按「🎲 換一張」，並可透過手機分享功能分享給家人朋友。

### English
The Morning Greeting feature creates a friendly daily greeting based on the date. You can change the theme and share the greeting with family and friends.

# 🆘 SOS 緊急求助 / Emergency SOS

進入「安全 → SOS 緊急求助」。

按下緊急求助後，系統會再次詢問確認以避免誤觸。可選擇撥打 **119** 或已設定的家人電話。

> SOS 功能需要裝置具備電話撥號能力。WECARE 不是緊急救援中心，也不會自動代替使用者聯絡救護單位。

### English
Emergency SOS provides quick access to Taiwan emergency number **119** and saved family contacts. A confirmation step helps reduce accidental activation. WECARE itself is not an emergency dispatch service.

# 🔐 資料與隱私 / Data & Privacy

目前 WECARE 多數個人設定及日常紀錄儲存在使用者裝置的瀏覽器本機儲存空間，包括稱呼、用藥設定與紀錄、飲食、行程、到家打卡、興趣、緊急聯絡人及顯示偏好。

## 自動清理

| 資料 | 保留方式 |
|---|---|
| 用藥完成紀錄 | 約 90 天 |
| 飲食紀錄 | 約 90 天 |
| 到家打卡 | 約 30 天 |
| 過期行程 | 約 30 天 |
| 用藥設定 | 保留 |
| 稱呼 | 保留 |
| 興趣 | 保留 |
| 緊急聯絡人 | 保留 |

使用者可在「我的 → 儲存空間」執行「🧹 立即清除舊紀錄」。

> 若清除瀏覽器網站資料、更換瀏覽器或更換裝置，本機保存的資料可能不會自動移轉。

### English
Most WECARE settings and daily records are stored locally in the browser. Clearing browser/site data may remove locally stored WECARE information.

# ❓ 常見問題 / FAQ

### Q1. 為什麼天氣顯示不正確？
請確認瀏覽器是否允許 WECARE 使用定位。若定位失敗，系統可能使用預設地區取得天氣。

### Q2. 為什麼放大鏡看不到畫面？
請確認已允許相機權限、使用 HTTPS 開啟 WECARE，且沒有其他 App 正在占用相機。

### Q3. 為什麼麥克風沒有反應？
請檢查瀏覽器及系統麥克風權限，並確認已按「開始環境偵測」。停止功能後，WECARE 會關閉使用中的麥克風串流。

### Q4. 為什麼換手機後資料不見了？
目前主要資料保存在原本瀏覽器的本機儲存空間，不會自動同步到其他裝置。

### Q5. 為什麼沒有收到系統推播？
目前「吃藥提醒」主要是 App 內提醒與紀錄功能，並非所有瀏覽器都會提供背景系統推播。

### Q6. SOS 會自動通知救護車嗎？
不會。SOS 主要提供快速撥打 119 或已設定的家人電話，仍需由使用者完成電話操作。

### Q7. 環境音量百分比是分貝嗎？
不是。這是根據裝置麥克風訊號計算的相對音量指標，不能當作醫療或專業噪音測量結果。
